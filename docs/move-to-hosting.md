# Переезд сайта на свой домен: что сделать для поиска

Сейчас сайт открыт на GitHub Pages только для проверки (https://sanuax.github.io/sayanmramor-site/).
Поэтому все страницы закрыты от поисковиков, а адреса в превью ссылок указывают на GitHub.
Сделано 2026-11-13. В день переезда:

1. **Открыть сайт поисковикам.** Удалить на всех страницах строку
   `<meta name="robots" content="noindex, nofollow" data-test-hosting>` и комментарий над ней:
   `grep -rln 'data-test-hosting' --include=*.html .`
   На `podborka.html` останется вторая строка `noindex` (личная подборка посетителя): её не трогать.
2. **Адреса картинки превью.** Заменить `https://sanuax.github.io/sayanmramor-site/` на адрес
   нового сайта в `og:image` (все страницы) и в `image` разметки организации (`index.html`).
3. **robots.txt и sitemap.xml** в корне домена: в `robots.txt` строка `Sitemap:` с полным адресом
   карты; в `sitemap.xml` 18 страниц (все, кроме `podborka.html`).
4. **canonical.** На каждой странице `<link rel="canonical" href="...">` с её полным адресом на
   новом домене.
5. **Яндекс.Вебмастер и Google Search Console.** Добавить сайт, подтвердить права, отправить
   `sitemap.xml`. Если домен тот же (`sayanmramor.ru`), старые адреса Bitrix перестанут открываться:
   301 с самых посещаемых старых страниц на новые (список берётся в Вебмастере, «Страницы в поиске»).
6. **Копия на GitHub Pages.** Если сайт уедет не на GitHub, выключить Pages или поставить с неё
   переадресацию, чтобы в поиске не было двух одинаковых сайтов.
7. **Карточки организации.** Адрес сайта в Яндекс Бизнесе (Яндекс.Карты), 2ГИС и ВКонтакте.
