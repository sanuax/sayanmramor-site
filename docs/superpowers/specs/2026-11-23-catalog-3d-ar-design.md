# «Готовые изделия»: 3D и AR (2026-11-23)

Одобрено владельцем 2026-11-23 («да, согласен, делай»).

## Зачем

Покупатель готового изделия видит его со всех сторон (3D) и ставит у себя в комнате в настоящем
размере (AR), не приезжая в шоурум. Изделия уникальные и дорогие (до 4 млн ₽): чем увереннее
человек в размере и виде, тем охотнее он нажимает «Запросить».

## Что входит

1. **Названия с камнем** (по образцу «Консоль из мрамора Nero Marquino»):
   Ракушка из мрамора Nero Marquino; Ваза настольная из оникса Orange; Ванная из оникса Orange;
   Арт-стол из мрамора Bianco Carrara (бывший «белый»); Арт-стол из мрамора Nero Marquino
   (бывший «чёрный»); Статуя из мрамора Bianco Carrara; Стол из мрамора Bianco Carrara.
2. **Модели в камне.** STL владельца (`D:\photo_marble\Stl модели готовых изделий`, мм, реальный
   размер, без цвета) упрощаются для сайта (~1-3 МБ на изделие) и «одеваются» в камень из
   каталога калькулятора: Negro Marquina (= Nero Marquino, совпадает с консолью), Bianco Carrara,
   Onice Orange. Камень проецируется с трёх сторон с мягким смешиванием и запекается в текстуру
   по развёртке (без швов), в масштабе плиты (фото = вся плита).
3. **Кнопка «3D»** на фото карточки (рядом с «N фото»). Открывает окно поверх страницы, как
   просмотр фото: изделие на светлом фоне, крутится мышью/пальцем, подпись = название + размер
   из модели; кнопка «Поставить у себя (AR)».
4. **AR в родных приложениях телефона:** iPhone/iPad = Quick Look (готовый `.usdz`, масштаб
   заперт 1:1), Android = Google Scene Viewer (готовый `.glb`, `resizable=false`). На компьютере
   кнопка AR показывает QR-код: телефон открывает каталог с окном 3D этого изделия.

## Чего нет

- Консоль без кнопки 3D, пока нет её модели (появится сама, когда в данных будет модель).
- Свечение оникса изнутри в AR невозможно (форматы AR этого не умеют); в окне 3D на сайте
  блеск полировки, без имитации просвета.
- Модели грузятся только по нажатию «3D» (страница каталога не тяжелеет).

## Ограничения

- Фото плит в каталоге 850×500: вблизи в AR рисунок большого стола мягковат. Крупные фото плит
  от поставщика улучшат результат (тот же скрипт).
- Остальной вид карточек не меняется (решение 37b1597 / c110f7b).

## Как сделано (решения исполнителя)

- `scripts/build_product_models.py` (Python 3.13 + trimesh, fast-simplification, xatlas,
  usd-core; venv вне репозитория): STL → упрощение → нормали с изломом по острым рёбрам →
  развёртка xatlas → запекание камня → `assets/products/<id>/model.glb` + `model.usdz`.
  Повторяемый запуск; источники STL и фото камней передаются путями.
- `data/products.json`: у изделия поле `model` `{glb, usdz, size_mm:[ширина, глубина, высота]}`.
- Окно 3D: `js/model-view.js` на уже лежащем в `vendor/three` three.js 0.160 + OrbitControls,
  свой небольшой разбор GLB (формат свой, без GLTFLoader); загружается только по нажатию.
- QR: библиотека qrcode как в калькуляторе (`vendor/qrcode`).
