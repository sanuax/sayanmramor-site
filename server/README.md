## lead.php -- заявки с сайта на почту

Форма «Получить расчёт» (js/offer-form.js) отправляет заявку на `https://sayanmramor.ru/lead.php`.
Этот файл кладётся на хостинг старого сайта sayanmramor.ru (Битрикс, PHP) и отправляет письмо
на sayan-mramor@yandex.ru через почту хостинга, как это делал старый сайт. Данные остаются в России.

Как положить:
1. Войти в панель управления хостингом сайта sayanmramor.ru.
2. Открыть «Менеджер файлов» и папку сайта -- ту, где лежат `index.php` и папка `bitrix`.
3. Загрузить туда `lead.php` из этой папки (имя файла не менять).
4. Проверка: `https://sayanmramor.ru/lead.php` в браузере отвечает `{"ok":false,"error":"method"}` --
   значит файл на месте; заявку он примет только из формы сайта.

Что внутри: получатель (`TO`), отправитель на домене хостинга (`FROM`), сайты, с которых принимаются
заявки (`ALLOWED_ORIGINS`), ловушка для ботов (поле `website`), не больше 5 заявок с одного адреса
за 10 минут, файл клиента и паспорт изделия до 15 МБ во вложении, «Ответить» в письме пишет клиенту.

Если домен sayanmramor.ru когда-нибудь переведут на новый сайт или старый хостинг отключат, файл
нужно перенести на другой сервер с PHP и поменять адрес `LEAD_URL` в js/offer-form.js.
